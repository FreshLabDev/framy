## 1. Что изменилось на рынке и ломает исходный план

- **OpenAI больше не делает видео через API.** Sora 2 и Videos API отключены 24 сентября 2026 года, замены нет. Ключ OpenAI в framy работает только для картинок.
- **Из Gemini API убрали Veo.** Veo 3.1 preview отключён 22 октября 2026 года, Imagen ещё 17 августа. Видео по ключу Gemini теперь делает одна модель, `gemini-omni-1.1-flash`. Длительность она выбирает сама (3–10 с), поэтому точную цену до запуска не показать, только «до $1» (на 720p).
- **У Gemini нет бесплатного уровня для картинок и видео.** Ключ без включённой оплаты проходит проверку списком моделей и падает только на генерации (429 с `limit: 0`).
- **OpenRouter стал главным путём.** У него отдельные Images API (`POST /api/v1/images`) и Videos API (`POST /api/v1/videos`) и публичные каталоги без ключа:
  - `GET /api/v1/images/models`: 61 модель;
  - `GET /api/v1/videos/models`: 30 моделей;
  - для каждой модели в каталоге есть допустимые значения параметров (`enum`, `range`) и цены. Форму на сайте можно строить из этих данных, не из кода.
- **Veo 3.1, Kling, Seedance, Wan, Hailuo, Grok Imagine, Runway, FLUX Video есть только через OpenRouter.**

| Ключ | Картинки | Видео | Подключение | Баланс по ключу |
|:--|:--|:--|:--|:--|
| OpenRouter | почти всё (61 модель, в том числе GPT Image и Nano Banana) | 30 моделей | OAuth PKCE «в один клик», без регистрации приложения | `GET /api/v1/key`: потрачено и остаток лимита ключа |
| OpenAI | `gpt-image-2.5-sunburst`, `gpt-image-2.5-flare`, `gpt-image-2` | нет | вставить ключ | узнать нельзя |
| Gemini | Nano Banana 2.1, 3.1 Flash, 3.1 Flash Lite, 3 Pro | только `gemini-omni-1.1-flash` | вставить ключ (проект с оплатой) | узнать нельзя |

Твоя идея «если подключены и Gemini, и OpenRouter, показывать оба варианта» работает, но не так, как кажется. OpenRouter продаёт по цене провайдера без наценки. Комиссия около 5,5% берётся только при пополнении кредитов. Поэтому цена Nano Banana 2.1 напрямую и через OpenRouter одинаковая. Различаются две вещи:
- **с какого баланса спишут;**
- **какие настройки доступны.** У прямого Gemini есть `thinking_level` и поиск Google, у прямого OpenAI маска и произвольные размеры до 4K. Через OpenRouter этого нет.

Так их и надо показывать: две строки с одинаковой ценой и разными возможностями.

## 3. Цена и валюта

Типов тарификации пять:
- по таблице (размер × качество);
- за мегапиксель (FLUX.2);
- токенами по формуле (OpenAI, Gemini);
- за секунду с поправкой на разрешение и звук (видео);
- динамическая, когда итог известен только после генерации (Riverflow 2.5, Gemini Omni).

Как показывать:
- **До запуска:** «$0,034 · ≈1,53 ₴», а где точно не посчитать, «до $X».
- **После запуска:** фактическую цену из ответа: `usage.cost` у OpenRouter, токены у OpenAI и Gemini. В записи генерации хранить оценку, факт, курс и дату курса.

Курс:
- **Основной источник:** API НБУ (`bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json`). Проверено: USD 45,5382 на 27.10. После 15:30 по Киеву API отдаёт курс на следующий день. BYN в нём нет.
- **Запасной источник:** `fawazahmed0/currency-api` (CC0, есть UAH и BYN).

Страна:
- **На сайте и в Mini App:** заголовок `CF-IPCountry`, включается в настройках Cloudflare. Работает ли он через наш Cloudflare Tunnel, не проверено. Достаточно залогировать заголовок на реальном домене.
- **В боте:** IP пользователя не виден. Сначала берём сохранённый выбор, потом подсказку по `language_code`, иначе USD.

## 5. Telegram

### Альбом в группе: главное ограничение

Метода «получить сообщение по id» в Bot API нет. В `reply_to_message` приходит одно фото, соседей по альбому там нет. Элементы альбома приходят отдельными сообщениями. Бот в privacy mode их не видит.

Варианты по порядку:
1. **Бот администратор группы (без лишних прав).** Тогда он видит все сообщения и кэширует альбомы по `media_group_id`: `file_id`, автор, дата, без текста, хранение 48 часов. Это единственный путь, который полностью подтверждён документацией. Просить админа стоит при первом `/f` на альбом, а не при добавлении бота.
2. **Патч нашего `telegram-bot-api`: метод `getMessages`.** Внутри сервера этот вызов TDLib уже используется для `forwardMessages`, патч оценивается в 40–60 строк C++. Отдаст ли Telegram боту сообщения, которых тот не видел, не проверено.
3. **Пересылка соседних id в служебный чат с эвристикой.** Только как временная мера.
4. **Альбом в личку, на сайт или в Mini App.**

Экран «вот такие фото взяты» нужен в любом случае: он показывает, что бот реально получил.

У админства есть второй плюс. Админ может слать **ephemeral-сообщения** (Bot API 10.2–10.3) в любое время. Такие сообщения в группе видит только один человек. На них можно сделать панель выбора модели и настроек для того, кто вызвал `/f`, не засоряя чат. Публичными остаются превью и результат.

### Поток `/f` (как ты описал, по методам)

1. `/f …` → реакция 👀 на команду и `sendChatAction`.
2. Режим определяется так:
   - без reply: картинка с нуля;
   - reply на фото: правка;
   - reply на фото из альбома: все фото альбома из кэша.
3. Превью: коллаж или короткая анимация «фото влетают в рамку». Отправка через `sendPhoto` или `sendAnimation`, кнопки «Да» (`style: success`) и «Нет» (`style: danger`), а также «Модель», «Настройки», «Открыть на сайте». Стили кнопок появились в Bot API 9.4.
4. «Нет» → `deleteMessage`.
5. «Да» → `editMessageMedia` в заготовленную петлю «идёт генерация». Петля уже загружена, берётся по `file_id`, загрузка не нужна.
6. Готово:
   - быстро → `editMessageMedia` в результат;
   - долго или видео → новое сообщение ответом на команду, а прогресс удалить. Правка не даёт уведомления, а ответ даёт.
7. Ответ текстом на результат бота работает как доработка. Такие ответы приходят и в privacy mode, команда не нужна.

Ограничения, которые надо помнить:
- медиа обратно в текст не превращается;
- в больших группах отправка видео может вернуть `message_id = 0`;
- в группе не больше 20 сообщений в минуту;
- кнопка `web_app` работает только в личке. В группе Mini App открывается ссылкой `t.me/framyin_bot/app?startapp=<подписанный payload>`, как в maply.

### Что ещё даёт Bot API 10.x

- **Guest mode (10.0).** Человек пишет `@framyin_bot сделай в стиле аниме` ответом на фото в любом чате, где бота нет, даже в личке с другом. Документация Telegram прямо приводит генерацию картинок как пример. Альбомы так не решаются, но для одиночных фото это вход в любой чат.
- **Inline.** История генераций по `file_id` (`InlineQueryResultCachedPhoto` / `CachedVideo`) и кнопка в Mini App над результатами.
- **Личка.** Прогресс через `sendRichMessageDraft` с кнопкой «Стоп» (`can_stop`, 10.3) и эффект на готовом сообщении.
- **Вход на сайт.** Новый Telegram Login на OpenID Connect (`oauth.telegram.org`). Со scope `telegram:bot_access` бот может прислать в личку то, что человек сгенерировал на сайте. Ключ пользователя один везде: Telegram user id из claim `id`, не `sub`.
- **Mini App.** Fullscreen, `shareMessage` и `savePreparedInlineMessage` (отправка результата в любой чат), `downloadFile` (оригинал), `CloudStorage` (настройки). С 20.07.2026 методы Mini App работают только с зарегистрированного origin, поэтому сайт и Mini App живут на одном домене и одном фронтенде, как maply.
- **Локальный сервер Bot API.** Загрузка до 2000 МБ вместо 50, отправка файлов путём с диска.

В нашем клиенте `tg` для этого не хватает:
- полей сообщения: `media_group_id`, `animation`, `live_photo`;
- апдейта `edited_message`;
- методов `sendAnimation`, `setMessageReaction`, `savePreparedInlineMessage`, `answerGuestQuery`, `deleteMessages`, кнопок `web_app` и `login_url`.

Полный список в [telegram.md](telegram.md), раздел 9.

## 6. Что берём из maply

- **Анимации.** `internal/anim` рисует петли на CPU и кодирует их ffmpeg за секунды. На нём делаются петля «идёт генерация» в цвете framy и персональная анимация превью: миниатюры фото пользователя собираются в рамку.
- **Отправка.** Загрузка MP4 без звука документом, после чего Telegram показывает его как гифку. Дальше всё по `file_id`. `editMessageMedia` текст → анимация. Кэш `file_id`, чтобы одно и то же не рисовать и не грузить дважды.
- **Карточки.** `internal/card`: headless Chromium снимает HTML-страницу. Подходит для коллажей и карточек «до/после».
- **Авторизация.** `internal/auth`: проверка `initData`, подписанный `startapp`, проверка членства в группе.
- **Фронтенд.** Один фронтенд для сайта и Mini App, safe areas, `?v=hash` от кэша Cloudflare, `i18n` на 16 языков.

## 7. Что я думаю о проекте

Проект сильный, но это первый в линейке Asterfield, который не «узкий». Остальные боты делают одну вещь, а framy — это продукт с сайтом, каталогом из ~90 моделей, ключами трёх провайдеров и тремя интерфейсами. Работы больше, чем у maply, примерно в разы.

Что в нём хорошо:
- **Позиционирование.** Типичный бот-генератор в Telegram перепродаёт кредиты с наценкой. framy честно показывает цену провайдера в гривнах и не берёт сверху. Это отличие, которое легко объяснить.
- **Глубина Telegram.** Альбом одной командой, превью с подтверждением, панель настроек, видная только автору, guest mode в чужих чатах, история в inline. Такого набора у конкурентов я не видел. Правда, сравнение с конкурентами отдельно не проводил.
- **Задел.** Готовая база из maply (анимации, Mini App, авторизация) и свой Bot API сервер.

Где риск:
1. **Аудитория и ключи.** У большинства людей в Telegram нет API-ключей, а бесплатный лимит маленький. Всё держится на подключении OpenRouter через OAuth: кнопка, вход на openrouter.ai, пополнение картой там же, возврат. Это надо сделать первым и отполировать. Ключи OpenAI и Gemini для обычного человека трудны: Gemini требует проект с оплатой, OpenAI может потребовать верификацию организации. Это режим для энтузиастов.
2. **Каталог меняется каждый месяц.** За год закрыты Sora, Imagen, Veo в Gemini API, `gpt-image-1` (23.10). Модели и цены берём из API OpenRouter и обновляем каждый час. Вручную описываем только прямые OpenAI и Gemini. Модели с `expiration_date` прячем заранее.
3. **Чужие фото в группах.** `/f` в ответ на фото другого человека — самый вероятный источник проблем (раздень, высмей). Модерация провайдера ловит не всё, а на бесплатном тарифе это наш аккаунт. Нужно решение: разрешать ли править фото, которое прислал не автор команды, подписывать ли результат именем того, кто его заказал, давать ли автору исходного фото кнопку «удалить». Решение за тобой.
4. **Хранение и трафик на ws04.** Результаты надо сразу копировать к себе: ссылки провайдеров живут от часа до 48 часов. Видео быстро займут диск, нужен срок хранения. Через Cloudflare Tunnel большие загрузки упрутся в лимит тела запроса, по памяти 100 МБ, не проверено. Запросы дольше 125 секунд Cloudflare обрывает, поэтому всё идёт через очередь задач: ответ сразу, результат потом.
5. **Ключи пользователей.** Шифровать отдельным ключом для каждой записи (envelope encryption, AES-GCM), главный ключ держать вне базы. Ключ не уходит в браузер и не логируется. Из Mini App и с сайта ключ принимаем, в чат бота его вводить не надо.
6. **Деньги внутри Telegram.** Если когда-нибудь появится платный тариф, внутри бота и Mini App он продаётся только за Stars.

Как бы я резал на этапы:
1. **Картинки.**
   - сайт с промптом и выбором модели из каталога;
   - подключение OpenRouter в один клик и вставка ключей OpenAI/Gemini;
   - цена в USD и гривнах;
   - бесплатный лимит с общим бюджетом;
   - `/f` в группах и личке: превью, «Да/Нет», петля генерации, альбомы через админство.
2. **Видео.**
   - кадры, референсы, длительность, звук, ожидание с таймером;
   - доставка готового видео в Telegram.
3. **Mini App и Telegram дальше.**
   - Mini App: fullscreen, `shareMessage`, `downloadFile`;
   - вход на сайт через Telegram OIDC;
   - inline-история, ephemeral-панель настроек, guest mode;
   - патч `getMessages`.
